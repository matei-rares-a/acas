sequenceDiagram
    autonumber
    actor U as User
    participant UI as Client App
    participant API as Server
    participant DB as Database

    U->>UI: Enter client_id, password

    rect rgb(220, 255, 220)
    Note over UI,API: Commit
    UI-->>API: GET /parameters
    API-->>UI: 200 { P, G }
    UI-->>UI: x = derive(password, client_id) mod Q
    UI-->>UI: r = random in [1, Q-1]
    UI-->>UI: Commitment t = G^r mod P, check t is a valid subgroup element
    UI-->>API: POST /login/commit  { client_id, commitment_t }
    API-->>DB: SELECT secret_y WHERE client_id=?
    DB-->>API: {secret_y}
    break missing client_id or commitment_t field
        API-->>UI: 400 { reason: missing parameters }
    end
    break T not in subgroup
        API-->>UI: 422 { reason: invalid commitment }
    end
    break user not found
        API-->>UI: 404 { reason: user not registered }
    end
   
    API-->>API: Generate random session_id <br/><br/> binding = H( TCP_peer_addr | User-Agent | session_id | client_id | T )<br/><br/> Generate challenge c = int(binding) mod Q  <br/><br/> Between request store{ T, c, binding, peer_addr, timestamp }
    API-->>UI: 200 { session_id, challenge_c }
   
    Note over UI,API: Verify
    UI-->>UI: s = (r + c * x) mod Q
    UI->>API: POST /login/verify  { solution_s }<br/><br/> X-Auth-Session: session_id 
    break session_id not found
        API-->>UI: 404 { reason: invalid session_id }
    end
    break session time expired  
        API->>API: DELETE sessions[session_id]
        API-->>UI: 401 { reason: session expired }
    end
    break s out of range [1, Q)
        API-->>API: DELETE sessions[session_id]
        API-->>UI: 422 { reason: invalid solution }
    end
    API -->>API: binding = H( TCP_peer_addr | User-Agent | session_id | client_id | T )
    break binding mismatch
        API-->>API: DELETE sessions[session_id]
        API-->>UI: 401 { reason: session binding mismatch }
    end
    API-->>DB: SELECT secret_y WHERE client_id=?
    DB-->>API: { secret_y }
    API-->>API: Check  G^s == T * y^c  (mod P)
    alt proof valid
        API-->>DB: INSERT AuthToken(JWT, client_id, issued_at)
        DB-->>API: OK
        API-->>API: DELETE sessions[session_id]
        API-->>UI: 200 { JWT } 
        UI-->>U: Authenticated - JWT stored
    else proof invalid
        API->>API: DELETE sessions[session_id]
        API-->>UI: 401 { reason: verification failed }
        UI-->>U: Error - unauthorized
    end
    end
