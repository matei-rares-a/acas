  KEY DIFFERENCES:
  SRP-6a : Server stores a verifier (salt + hash) — breached DB reveals
           precomputed verifiers but NOT the password directly.
           Faster login: 3 meaningful rounds (library uses C for modexp).

  J-PAKE : No verifier stored — server never holds any password-derived
           material between sessions. ZKPs prove knowledge at every step.
           True forward secrecy: past sessions safe even if password leaked.
           Extra round needed because ZKPs require two-way key-share exchange.
