  Schnorr-EC-Lib: c*Y (arbitrary-point mult) still uses pure Python wNAF; all k*G via OpenSSL.
  Schnorr-PoW: uses Python built-in pow(a, b, n) - same group and same interactive construction as the actual server.
  pysnark Groth16: Fiat-Shamir c=SHA256(T_c||Y_c||T_s||Y_s); EC verify s·G=T+c·Y outside circuit (soundness); SNARK proves ZK witness.
  pysnark security = Schnorr-EC-Lib security (DLOG/secp256r1) + non-interactive (Fiat-Shamir) + ZK (circuit hides x,r).
