  ALGORITHM SELECTION GUIDANCE:
  ML-KEM-512  : equivalent quantum resistance to AES-128; suitable for non-critical data.
  ML-KEM-768  : recommended general-purpose choice (NIST recommended minimum for new systems).
  ML-KEM-1024 : highest security margin; use when long-term confidentiality matters (>10 years).
  ECDH P-256  : classical baseline; NOT quantum-safe; widely deployed / very fast (native).

  IMPORTANT — kyber-py vs liboqs performance:
  These timings use a pure Python reference. With liboqs (C library), ML-KEM is typically
  ~0.01–0.10 ms per operation (100–500x faster), making it competitive with ECDH P-256.
  Real-world TLS 1.3 + ML-KEM-768 (Hybrid X25519MLKEM768) adds < 1 ms overhead vs ECDH.
